## Возможности

Всё считается **локально** — тяжёлые операции (кодирование, ИИ-модели, апскейл) не уходят на сторонние серверы.

| | |
|---|---|
| 🎬 **Конвертер и сжатие** | Видео/аудио/изображения через локальный FFmpeg, матрица энкодеров (x264/x265/AV1, NVENC) |
| 📄 **PDF-тулкит** | Слияние, разбиение, поворот, водяной знак, номера страниц, сборка из изображений, извлечение текста |
| ⬇️ **Загрузчик и музыка** | yt-dlp «из коробки» — видео и аудио с YouTube и других сайтов |
| 🍿 **Фильмы и сериалы** | Каталог TMDB, оценки и статистика, поиск раздач на трекерах, встроенный торрент-плеер |
| 🔎 **Апскейл и плавность видео** | Локальные ONNX-модели (Real-CUGAN, Real-ESRGAN, RIFE/IFRNet/CAIN), GPU-ускорение вплоть до TensorRT |
| 🎙️ **Лекционный диктофон** | Запись + VAD, расшифровка Whisper, ИИ-конспект по предметным пресетам, разделение говорящих |
| 🔊 **Аудиокниги (TTS)** | Озвучка текста голосом (XTTS, F5-TTS) с профилями и референсами |
| 🌐 **Обход блокировок** | Встроенный движок Zapret + локальный прокси (sing-box) с подписками, спидтест, сканер портов, kill-switch |
| 🌡️ **Монитор железа** | Температуры и загрузка CPU/GPU/памяти в реальном времени, анализатор занятого места на диске (аналог WinDirStat) |
| 📚 **Книги** | OPDS-каталоги, избранное, закладки |
| 🤖 **ИИ-чат** | Локальные модели через Ollama, потоковые ответы |
| 🗂️ **Своё пространство** | Задачи (с распознаванием дат/времени на нескольких языках), заметки, markdown-редактор, канвас, база знаний, закладки с режимом «отложить на чтение» |
| 🎮 **Игры** | Лаунчер карточек с автосбором библиотеки Steam/Epic, версионный бэкап сохранений |
| 💰 **Бюджет** | Локальный трекер доходов/расходов по категориям с помесячными графиками |
| ⚡ **Автоматизация** | Быстрый лаунчер программ/скриптов + запуск по расписанию через Планировщик заданий Windows |
| 📸 **Скриншоты и запись экрана** | Библиотека скриншотов и скринкастов с превью и плеером |
| 🗄️ **Веб-архив** | Локальный краулер сайтов с сохранением в офлайн-архив (.sitebak) |
| 🔑 **Менеджер паролей** | Зашифрованное локальное хранилище логинов/паролей/заметок |
| 🛠️ **Инструменты** | JSON/regex/base64, конвертер систем счисления, хеши, UUID и другие утилиты разработчика |
| 📦 **Установщик приложений** | Каталог winget с избранным и массовой установкой |

Плюс: 5 тем оформления, 6 акцентных цветов, адаптивный интерфейс под узкие окна.

## Установка

1. Скачайте `MoonApp-Setup-x.y.z.exe` со страницы **[Releases](https://github.com/NoonLicht/MoonApp/releases/latest)**.
2. Запустите — установка не требует прав администратора.
3. Рядом с программой появится папка `storage\` со всеми данными.

> Windows SmartScreen может предупредить о неизвестном издателе (сборка ещё не подписана
> сертификатом) — «Подробнее» → «Выполнить в любом случае».

Приложение само проверяет обновления и предлагает установить новую версию, не трогая `storage`.

## Запуск из исходников

Требуется **Node.js ≥ 20**.

```bash
git clone https://github.com/NoonLicht/MoonApp.git
cd MoonApp
npm install
npm run rebuild:electron   # пересборка better-sqlite3 под Electron
npm start                  # сборка web-части + запуск приложения
```

| Скрипт | Назначение |
|---|---|
| `npm run dev` | Только Vite dev-сервер (фронт на `:5173`, API проксируется на `:4000`) |
| `npm run start:server` | Только Express-сервер без UI (`:4000`) |
| `npm run typecheck` | Проверка типов (фронт + серверные TS-исходники) |
| `npm test` | Тесты (Vitest) |
| `npm run dist` | Сборка NSIS-инсталлятора в `release/` |

## Технологии

Electron 31 · React 18 · TypeScript · Vite · Express · SQLite (better-sqlite3) · ONNX Runtime · Vitest

## Где хранятся данные

Всё — в папке `storage\` рядом с программой. Она не удаляется при деинсталляции и не
затрагивается обновлениями: настройки, ключи, скачанные модели и файлы остаются на месте.

## Безопасность

- Локальный API слушает только `127.0.0.1`, каждый запрос требует сессионный токен.
- Жёсткий CSP в Electron-окне: инлайн-скрипты и внешние загрузки запрещены.
- Секреты шифруются через Electron safeStorage (DPAPI) с фолбэком на AES-256-GCM.
