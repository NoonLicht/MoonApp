# PersonalApp

Персональная панель утилит для Windows: медиа, обход блокировок, мониторинг железа, книги, ИИ-чат и многое другое — в одном нативном desktop-приложении на Electron.

**Стек:** Electron 31 · React 18 · TypeScript · Vite · Express · SQLite (better-sqlite3) · Vitest

---

## Возможности

| Модуль | Описание |
|---|---|
| **Конвертер файлов** | Видео/аудио/изображения через локальный FFmpeg — файлы не покидают компьютер |
| **Сжатие видео** | Матрица энкодеров (x264/x265/AV1, NVENC), Express-режим с рекомендациями по железу |
| **Загрузчик видео** | yt-dlp: YouTube и другие сайты, слияние DASH-потоков через FFmpeg |
| **Музыка** | Поиск и скачивание аудио |
| **Аудиокниги (TTS)** | Озвучка текста в аудиокниги (XTTS, F5-TTS), референсы голоса, профили |
| **Веб-архиватор (.sitebak)** | Снятие офлайн-копий сайтов (краулер с Playwright или Fetch-режимом), сжатие zstd |
| **Лекционный диктофон** | Запись, VAD-нарезка, расшифровка (whisper), конспекты через Ollama |
| **Обход блокировок** | Zapret-движок: стратегии DPI-обхода, быстрое переключение из трея |
| **Прокси (sing-box)** | Локальный прокси с поддержкой подписок |
| **Монитор системы** | Температуры, загрузка CPU/GPU/памяти через LibreHardwareMonitor, графики recharts |
| **Установщик приложений** | Каталог winget + собственный каталог, избранное, массовая установка |
| **Книги** | OPDS-каталоги (Flibusta), избранное и закладки локально |
| **ИИ-чат** | Локальные модели через Ollama, стриминг ответов |
| **Моё пространство** | Задачи, заметки, markdown-редактор (TipTap), база знаний |
| **Мониторинг трафика** | Метрики прокси |

## Установка (готовая сборка)

1. Скачайте `PersonalApp-Setup-x.y.z.exe` со страницы [Releases](https://github.com/NoonLicht/MoonApp/releases).
2. Запустите установщик. По умолчанию приложение ставится в `%LOCALAPPDATA%\Programs\PersonalApp` (права администратора не нужны, путь можно изменить).
3. Рядом с программой создаётся папка `storage\` — в ней хранятся все данные.

> **Примечание:** Windows SmartScreen может предупредить о неизвестном издателе — сборка пока не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Компоненты, скачиваемые при первом запуске

Чтобы инсталлятор оставался лёгким, часть инструментов скачивается автоматически при первом использовании соответствующей функции (все — в `storage\`):

| Компонент | Папка | Когда скачивается |
|---|---|---|
| FFmpeg (+ ffprobe) | `storage\ffmpeg\` | конвертация / сжатие видео / TTS |
| yt-dlp | `storage\ytdlp\` | страница «Видео» |
| sing-box | `storage\singbox\` | страница «Прокси» |
| Zapret-движок | `storage\zapret\` | страница «Обход блокировок» |
| LibreHardwareMonitor | идёт в комплекте (`resources\app.asar.unpacked\server\vendor\lhm`) | монитор системы — из коробки |

## Запуск из исходников

Требуется **Node.js ≥ 20** (разрабатывался на 22/24).

```bash
git clone https://github.com/NoonLicht/MoonApp.git
cd MoonApp
npm install

# сборка нативного модуля better-sqlite3 под Electron
npm run rebuild:electron

# запуск в dev-режиме (Vite + Electron + сервер)
npm start
```

В dev-режиме данные хранятся в `storage/` рядом с проектом (путь можно переопределить переменной окружения `PERSONAL_APP_STORAGE`).

### Полезные скрипты

| Скрипт | Что делает |
|---|---|
| `npm start` | Сборка web-части + запуск Electron-приложения |
| `npm run dev` | Только Vite dev-сервер (фронт на http://localhost:5173, прокси на API :4000) |
| `npm run start:server` | Только Express-сервер (без UI) на http://localhost:4000 |
| `npm run typecheck` | Проверка типов (TS + серверные исходники) |
| `npm test` | Тесты (Vitest) |
| `npm run dist` | Сборка NSIS-инсталлятора в `dist/` |

## Сборка инсталлятора и выпуск обновлений

Подробная инструкция для разработчика — в `RELEASE.md` (локальный файл, в репозиторий не входит). Кратко:

```bash
npm version patch        # 0.1.0 -> 0.1.1 (коммит + тег v0.1.1)
git push --follow-tags   # GitHub Action соберёт и опубликует релиз
```

## Где хранятся данные

Всё — в папке `storage` рядом с программой (при установке по умолчанию: `%LOCALAPPDATA%\Programs\PersonalApp\storage`):

```
storage\
├── settings.json      — настройки приложения (шифруемые секреты — в secrets.json)
├── secrets.json       — API-ключи (шифрование DPAPI под учётной записью Windows)
├── data.json          — данные «Моего пространства»
├── backups\           — авто-бэкапы настроек
├── downloads\         — загрузки из установщика приложений / музыки
├── convert\in|out\    — временные файлы конвертера
├── compressor\in|out\ — файлы сжатия видео
├── tts\               — референсы голоса и готовые аудиокниги
├── sitebak\           — веб-архивы .sitebak
├── lectures\          — записи лекций и расшифровки
├── zapret\            — движок обхода блокировок
├── ffmpeg\, ytdlp\, singbox\ — самозагружаемые бинарники
├── bin\lhm\           — генерируемые артефакты мониторинга
├── logs\              — журнал приложения
└── tmp\               — временные файлы
```

**Удаление приложения не затрагивает `storage`** — данные и скачанные инструменты сохраняются. Обновления заменяют только файлы программы.

## Настройка

Основные настройки — в приложении: раздел **Настройки** (шестерёнка в доке). Там же настраиваются:

- язык интерфейса (RU/EN/ES/FR/ZH/AR);
- путь к FFmpeg, конвертер по умолчанию;
- папка загрузок установщика приложений;
- параметры краулера (.sitebak), TTS, лекционного диктофона;
- автозапуск с Windows, сворачивание в трей, аппаратное ускорение;
- размер страницы в магазине приложений.

## Безопасность

- Локальный API слушает только `127.0.0.1`, каждый запрос требует сессионный токен (передаётся файлом, не через argv).
- Жёсткий CSP в Electron-окне: инлайн-скрипты и внешние загрузки запрещены.
- HTML из скачанных веб-архивов отдаётся с вырезанными скриптами (`script-src 'none'`).
- Секреты шифруются через Electron safeStorage (DPAPI) с фолбэком на AES-256-GCM.
