# MoonApp

Персональная панель утилит для Windows: медиа, обход блокировок, мониторинг железа, книги, ИИ-чат и многое другое — в одном нативном desktop-приложении на Electron.

**Стек:** Electron 31 · React 18 · TypeScript · Vite · Express · SQLite (better-sqlite3) · Vitest

---

## Возможности

| Модуль | Описание |
|---|---|
| **Конвертер файлов** | Видео/аудио/изображения через локальный FFmpeg — файлы не покидают компьютер |
| **Сжатие видео** | Матрица энкодеров (x264/x265/AV1, NVENC), Express-режим с рекомендациями по железу |
| **Загрузчик видео** | yt-dlp: YouTube и другие сайты, слияние DASH-потоков через FFmpeg |
| **Музыка** | Поиск и скачивание аудио |
| **Фильмы и Сериалы** | Каталог TMDB (тренды, подборки с листанием и плиткой «Все …», поиск, каст, трейлеры, компактное «где смотреть»), личные оценки 1–10 со сбросом, список просмотра и статистика; галерея с перемоткой; встроенный плеер (трейлер + торрент, источник которого задаёте вы сами) |
| **Аудиокниги (TTS)** | Озвучка текста в аудиокниги (XTTS, F5-TTS), референсы голоса, профили |
| **Веб-архиватор (.sitebak)** | Снятие офлайн-копий сайтов (краулер с Playwright или Fetch-режимом), сжатие zstd |
| **Лекционный диктофон** | Запись (микрофон + системный звук), VAD-нарезка, расшифровка (whisper), авто/ручной AI-конспект через выбранного провайдера (по умолчанию DeepSeek), разделение говорящих (двухдорожечный режим + диаризация sherpa) |
| **Обход блокировок** | Zapret-движок: стратегии DPI-обхода, быстрое переключение из трея |
| **Прокси (sing-box)** | Локальный прокси с поддержкой подписок |
| **Монитор системы** | Температуры, загрузка CPU/GPU/памяти через LibreHardwareMonitor, графики recharts |
| **Установщик приложений** | Каталог winget + собственный каталог, избранное, массовая установка |
| **Книги** | OPDS-каталоги (Flibusta), избранное и закладки локально |
| **ИИ-чат** | Локальные модели через Ollama, стриминг ответов |
| **Моё пространство** | Задачи, заметки, markdown-редактор (TipTap), база знаний |
| **Мониторинг трафика** | Метрики прокси |
| **Интерфейс** | Верхняя панель и док: на узком окне (меньше 1200px) поиск страницы прячется под кнопку с поповером, подписи «Фильмы / Сериалы» скрываются ниже 1050px, сетка магазина приложений — 5→4→2→1 колонки; темы (тёмная/OLED/светлая), акценты, плотность, размер шрифта |

## Установка (готовая сборка)

1. Скачайте `MoonApp-Setup-x.y.z.exe` со страницы [Releases](https://github.com/NoonLicht/MoonApp/releases).
2. Запустите установщик. По умолчанию приложение ставится в `%LOCALAPPDATA%\Programs\MoonApp` (права администратора не нужны, путь можно изменить).
3. Рядом с программой создаётся папка `storage\` — в ней хранятся все данные.

> **Примечание:** Windows SmartScreen может предупредить о неизвестном издателе — сборка пока не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Компоненты, скачиваемые при первом запуске

Чтобы инсталлятор оставался разумного размера, часть инструментов скачивается автоматически при первом использовании соответствующей функции (все — в `storage\`), а `yt-dlp` и `sing-box` теперь поставляются **в комплекте** с инсталлятором:

| Компонент | Где живёт | Когда доступен |
|---|---|---|
| FFmpeg (+ ffprobe) | `storage\ffmpeg\` | скачивается при первом использовании (конвертация / сжатие видео / TTS) |
| yt-dlp | в комплекте (`resources\app.asar.unpacked\server\vendor\ytdlp`), фолбэк — `storage\ytdlp\` | страницы «Видео» и «Музыка» — из коробки |
| sing-box | в комплекте (`resources\app.asar.unpacked\server\vendor\singbox`), фолбэк — `storage\singbox\` | страница «Прокси» — из коробки |
| Zapret-движок | `storage\zapret\` | скачивается на странице «Обход блокировок» |
| whisper.cpp + модель `ggml-small` | `storage\whisper\` | скачивается скриптом `npm run fetch:whisper` **или прямо в приложении** (страница «Лекторий» → кнопка-иконка ⚙ «Модель и ускорение», раздел есть и в Настройках) |
| Диаризация sherpa-onnx (бинарь + 2 модели, ~54 МБ) | `storage\diarize\` | скачивается кнопкой-иконкой 👥 на странице «Лекторий» → панель **«Говорящие»** (раздел есть и в Настройках); нужен Windows 10+ (распаковка через `tar.exe`) |
| LibreHardwareMonitor | в комплекте (`resources\app.asar.unpacked\server\vendor\lhm`) | монитор системы — из коробки |

> При сборке инсталлятора бинарники yt-dlp/sing-box подкладываются скриптом
> `npm run fetch:engines` (см. `scripts/fetch-engines.js`); в репозиторий `.exe` не коммитятся.
> Движок распознавания лекций качается отдельно (`npm run fetch:whisper`) — модель
> весит ~466 МБ, поэтому в инсталлятор не входит.
>
> Модель и сборку движка можно выбрать в самом приложении: страница «Лекторий» →
> кнопка-иконка **⚙ «Модель и ускорение»** в правом верхнем углу (тот же раздел есть
> в Настройках; подписи у кнопок страницы убраны — название показывается подсказкой
> при наведении). Там
> скачиваются модели tiny … large-v3 (+ q5-кванты) и сборки движка — CPU,
> OpenBLAS и CUDA 11.8/12.4: CUDA включает счёт на видеокарте NVIDIA, а кнопка
> «Проверить движок» прогоняет тестовый WAV и показывает реальный бэкенд.
>
> **AI-конспект** (кнопка «ИИ-конспект» / раздел в Настройках): провайдера и
> модель можно выбрать явно (по умолчанию **DeepSeek**), режим запуска —
> «умный авто» (сам после записи, но только если текста достаточно и он вырос с
> прошлой сборки), «всегда авто» или «вручную».
>
> **Разделение говорящих** (кнопка «Говорящие»): системный звук и микрофон пишутся
> в две дорожки, поэтому лектор и аудитория разделены уже «из коробки». Для
> различения голосов ВНУТРИ дорожки (кто из студентов отвечал) нужен пакет
> sherpa-onnx (~54 МБ, скачивается кнопкой). Разбор идёт на процессоре
> (~1 минута аудио за 5 секунд), поэтому авто-режим по умолчанию **выключен**.

## Запуск из исходников

Требуется **Node.js ≥ 20** (разрабатывался на 22/24).

```bash
git clone https://github.com/NoonLicht/MoonApp.git
cd MoonApp
npm install

# сборка нативного модуля better-sqlite3 под Electron
npm run rebuild:electron

# запуск в dev-режиме (Vite + Electron + сервер)
npm start
```

В dev-режиме данные хранятся в `storage/` рядом с проектом (путь можно переопределить переменной окружения `MOONAPP_STORAGE`).

### Полезные скрипты

| Скрипт | Что делает |
|---|---|
| `npm start` | Сборка web-части + запуск Electron-приложения |
| `npm run dev` | Только Vite dev-сервер (фронт на http://localhost:5173, прокси на API :4000) |
| `npm run start:server` | Только Express-сервер (без UI) на http://localhost:4000 |
| `npm run typecheck` | Проверка типов (TS + серверные исходники) |
| `npm test` | Тесты (Vitest) |
| `npm run dist` | Сборка NSIS-инсталлятора в `dist/` |

## Сборка инсталлятора и выпуск обновлений

Подробная инструкция для разработчика — в `RELEASE.md` (локальный файл, в репозиторий не входит). Кратко:

```bash
npm version patch        # 0.1.0 -> 0.1.1 (коммит + тег v0.1.1)
git push --follow-tags   # GitHub Action соберёт и опубликует релиз
```

## Где хранятся данные

Всё — в папке `storage` рядом с программой (при установке по умолчанию: `%LOCALAPPDATA%\Programs\MoonApp\storage`):

```
storage\
├── settings.json      — настройки приложения (шифруемые секреты — в secrets.json)
├── secrets.json       — API-ключи (шифрование DPAPI под учётной записью Windows)
├── data.json          — данные «Моего пространства»
├── backups\           — авто-бэкапы настроек
├── downloads\         — загрузки из установщика приложений / музыки
├── torrents\          — кэш торрент-плеера (страница «Фильмы и Сериалы»)
├── convert\in|out\    — временные файлы конвертера
├── compressor\in|out\ — файлы сжатия видео
├── tts\               — референсы голоса и готовые аудиокниги
├── sitebak\           — веб-архивы .sitebak
├── lectures\          — записи лекций и расшифровки
├── zapret\            — движок обхода блокировок
├── ffmpeg\            — самозагружаемый FFmpeg (yt-dlp/sing-box идут в комплекте)
├── ytdlp\, singbox\   — кэш бинарников (обычно уже в комплекте с приложением)
├── bin\lhm\           — генерируемые артефакты мониторинга
├── vault\, notes\     — «Моё пространство» (холсты и заметки)
├── logs\              — журнал приложения
└── tmp\               — временные файлы
```

**Удаление приложения не затрагивает `storage`** — данные и скачанные инструменты сохраняются. Обновления заменяют только файлы программы.

## Настройка

Основные настройки — в приложении: раздел **Настройки** (шестерёнка в доке). Там же настраиваются:

- язык интерфейса (RU/EN/ES/FR/ZH/AR);
- API-ключ TMDB и язык/регион каталога «Фильмы и Сериалы»;
- путь к FFmpeg, конвертер по умолчанию;
- папка загрузок установщика приложений;
- параметры краулера (.sitebak), TTS, лекционного диктофона;
- автозапуск с Windows, сворачивание в трей, аппаратное ускорение;
- стартовая страница приложения — список включает все страницы дока (Магазин, Конвертер, Фильмы и Сериалы, Лекции, Обход блокировок и т.д.);
- размер страницы в магазине приложений;
- автообновление приложения и ручное скачивание обновлений.

### Логи и диагностика

Если что-то работает не так — в **Настройках** есть раздел **«Логи и диагностика»** с кнопкой **«Собрать логи»**. Она собирает один текстовый файл со всеми событиями приложения:

- нажатия и переходы между страницами (что и во сколько открыли);
- изменения полей и горячие клавиши;
- изменения настроек с указанием страницы (`settings.change`: страница, путь, значение);
- **настройки по каждой странице** (магазин, конвертер, сжатие видео, видео/музыка, книги, монитор, ИИ-чат, синтез речи, лекции, обход блокировок, web-архив, заметки) — эффективные значения, а также локальные настройки интерфейса, которые хранятся не в `settings.json`;
- все запросы к локальному API, установки и скачивания;
- предупреждения и ошибки (интерфейса и сервера), включая ошибки Electron.

Файл `MoonApp-logs-<дата>-<время>.txt` появляется в папке `storage\` рядом с программой — его можно сразу переслать разработчику (кнопки «Показать в проводнике» и «Копировать путь»). Значения секретов и API-ключей в отчёт не попадают: для них пишутся только имена полей. Хранятся последние 10 отчётов.

## Безопасность

- Локальный API слушает только `127.0.0.1`, каждый запрос требует сессионный токен (передаётся файлом, не через argv).
- Жёсткий CSP в Electron-окне: инлайн-скрипты и внешние загрузки запрещены.
- HTML из скачанных веб-архивов отдаётся с вырезанными скриптами (`script-src 'none'`).
- Секреты шифруются через Electron safeStorage (DPAPI) с фолбэком на AES-256-GCM.
