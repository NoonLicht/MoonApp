# MoonApp Web Clipper

Расширение для Chrome/Edge/Brave: сохраняет страницу или выделенный текст в заметки MoonApp
(папка «Веб-клипы», с источником и цитатой).

## Установка

1. В MoonApp: **Настройки → Меню Проводника → Добавить пункты** — это же регистрирует протокол `moonapp://`
   для вашей учётной записи (работает только в установленной сборке).
2. В браузере откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное расширение» → выберите эту папку `browser-extension`.

## Использование

- Клик по значку расширения — сохранить текущую страницу (и выделенный текст, если он есть).
- Правый клик по странице или выделению → «Сохранить в MoonApp».
- Браузер один раз спросит разрешение открыть MoonApp — это защита от того, чтобы сайты сами создавали заметки.

## Ограничения

- Работает только с http/https-страницами; текст обрезается до 6000 символов.
- Ссылка передаётся через командную строку Windows, поэтому очень длинные выделения не поддерживаются.
- Заметки всегда создаются в папке «Веб-клипы»; существующие заметки не изменяются.
