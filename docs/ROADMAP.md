# ROADMAP — план улучшений MoonApp

Правила работы:

- **Один файл — один коммит** (чтобы любой шаг откатывался `git revert`).
- Новая логика сначала идёт отдельными самодостаточными модулями + тест; подключение к
  `index.ts` / страницам — отдельным коммитом.
- Каждая фаза закрывается зелёным `npm run typecheck`, `npm run lint`, `npm test`.
- Статус: ☐ не начато · ◐ в работе · ☑ готово.
