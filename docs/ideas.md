- Текстовые/dev-инструменты — одна страница «Инструменты»: JSON/XML форматтер, diff двух текстов, regex-тестер, base64/URL/hash (md5/sha), генератор UUID, конвертер систем счисления. Часто нужно любому пользователю компьютера, ноль внешних зависимостей.
- Менеджер паролей / хранилище секретов — у вас уже есть шифрованный storage/secrets.json и инфраструктура для ключей (TMDB/Kinopoisk) — расширить её до полноценного личного вольта с генератором паролей. Естественное продолжение того, что уже есть.
- PDF-тулкит — слияние/разбиение/OCR/конвертация в текст. Дополняет convert/compressor, спрашивают чаще, чем думаешь.
- Конвертер единиц + калькулятор (валюты, величины, программистский калькулятор) — тривиально, но реально используется постоянно.
- Сетевые утилиты — спидтест, пинг/трассировка, сканер портов, свой IP/WHOIS. Логично живёт рядом со страницей bypass (прокси), делит инфраструктуру.
- Скриншоты/запись экрана — с аннотацией (стрелки/блюр). Electron даёт desktopCapturer из коробки.
- Простой редактор изображений — кроп/ресайз/водяной знак/конвертация форматов, рядом с convert.
- Трекер расходов/бюджета — ручной ввод или импорт выписки CSV, категории, графики по месяцам (у вас есть recharts в зависимостях — уже готово к использованию).
- Планировщик задач Windows по-человечески — GUI поверх Task Scheduler: «выключить комп в 23:00», «запустить бэкап по расписанию» — многим сложно/лень лезть в системный планировщик.

Творчество/медиа (кроме того что уже есть)
- Скрин-заметки / доска (whiteboard) — свободный холст с картинками/текстом/стрелками, для быстрых набросков идей.
- Генератор плейлистов/тегирование музыки — раз есть music, можно добавить авто-теги (артист/обложка по названию файла) и умные плейлисты.

- Kill-switch для сети — при обрыве VPN/прокси рвать интернет полностью, чтобы не спалить реальный IP — логично живёт в bypass.
- Быстрый лаунчер приложений/команд (Alt+Space, как Raycast/PowerToys Run) — раз приложение уже в фоне и есть глобальные хоткеи в Electron.
- OCR из буфера — скриншот → распознанный текст сразу в буфер (используя тот же Whisper-стек? нет, тут нужен отдельный OCR-движок типа tesseract.js — но связка со скриншотами выше даёт цельную фичу).
- Оверлей FPS/статистики во время игр (RivaTuner-lite) — раз уже есть мониторинг железа, добавить in-game overlay через Electron overlay-окно.
- Менеджер игровых сейвов — бэкап/синхронизация save-файлов между переустановками (частая боль, простое дерево: путь→архив→версии).
- Страница с иконками для запуска игр и всего такого, что можно добавить вручную. можно добавить приложение, иконки, описание, фон
- Мониторинг Wi-Fi окружения — список сетей, сила сигнала, каналы (полезно при настройке роутера).
- Голосовые заметки с авто-транскрипцией — то же самое, что лекции, но короткие, быстрый режим «наговорил идею — получил текст».
- Читалка веб-статей (Reader Mode + сохранение офлайн, «read later») — вырезает рекламу/шум со страницы, сохраняет в вашу же библиотеку заметок.
- Трекер использования приложений/времени за компом — сколько времени в каком приложении (нужен системный хук активного окна на Windows).
